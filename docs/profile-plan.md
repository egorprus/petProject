# План: страница профиля пользователя

Сейчас ссылка в хедере (`client/src/widgets/Header/components/ActiveProfile.tsx`) ведёт на `/${login}`,
но маршрута нет. На сервере есть `GET /auth/me` и `GET /user/:id` (по `_id`), эндпоинтов изменения профиля нет.

Этапы идут по порядку, каждый следующий опирается на предыдущий.

## 1. Свой профиль с редактированием — в работе

- Страница `/profile` (только для авторизованного пользователя).
- Просмотр: аватар, имя, логин, дата регистрации.
- Редактирование имени и аватара.
- Смена пароля (с проверкой текущего).
- Ссылка в хедере ведёт на эту страницу.

## 2. Публичная страница `/u/:login`

- Другие пользователи видят имя, аватар, дату регистрации.
- Серверный эндпоинт поиска пользователя по логину (только публичные поля).
- Если открыт свой профиль — показывать кнопку перехода к редактированию (этап 1).
- Опционально: ссылка на расшаренный список фильмов, если `movieShareToken` задан.

## 3. Личный дашборд

- Сводка по разделам на странице профиля: количество фильмов (просмотрено / в планах / избранное),
  ближайшие события календаря, итог банка за текущий месяц.
- Серверный эндпоинт агрегированной статистики, чтобы не тянуть все записи на клиент.
